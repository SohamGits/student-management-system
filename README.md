## <picture><source media="(prefers-color-scheme: dark)" srcset="assets/readme-icons/book-open-page-variant-dark.svg"><img src="assets/readme-icons/book-open-page-variant.svg" alt="" width="22" height="22" align="absmiddle"></picture> About

**Student Management System** is a full-stack web application built with **Python** and **Django** that lets teachers and students manage classrooms, assignments, and submissions through **role-based dashboards**.

  <tr>

      <ul>
        <li>Create and manage classrooms</li>
        <li>Enroll students</li>
        <li>Publish assignments with optional file attachments</li>
        <li>Review student submissions</li>
      </ul>
    </td>

      <ul>

        <li>Access published assignments</li>

## <picture><source media="(prefers-color-scheme: dark)" srcset="assets/readme-icons/rocket-launch-dark.svg"><img src="assets/readme-icons/rocket-launch.svg" alt="" width="22" height="22" align="absmiddle"></picture> Installation

<details open>
<summary><b><picture><source media="(prefers-color-scheme: dark)" srcset="assets/readme-icons/package-variant-dark.svg"><img src="assets/readme-icons/package-variant.svg" alt="" width="18" height="18" align="absmiddle"></picture>&nbsp;&nbsp;Step-by-step setup</b></summary>

<br/>

**1. Clone the repository**

```bash
git clone https://github.com/SohamGits/student-management-system.git
cd student-management-system
```

**2. Create a virtual environment**

```bash
python -m venv venv
```

**3. Activate it**

```bash
# Windows
venv\Scripts\activate

# macOS / Linux
source venv/bin/activate
```

**4. Install dependencies**

```bash
pip install -r requirements.txt
```

**5. Apply migrations**

```bash
python manage.py migrate
```

**6. *(Optional)* Create a superuser for Django Admin**

```bash
python manage.py createsuperuser
```

</details>

## <picture><source media="(prefers-color-scheme: dark)" srcset="assets/readme-icons/console-dark.svg"><img src="assets/readme-icons/console.svg" alt="" width="22" height="22" align="absmiddle"></picture> Usage

```bash
python manage.py runserver
```

Then open **http://127.0.0.1:8000/** in your browser.
Local management commands use development defaults when no production
configuration is present. Production commands require explicit settings.

### Production configuration

Set `DEBUG=false`, a strong `SECRET_KEY`, `ALLOWED_HOSTS`, and a shared Redis
`REDIS_URL` in the deployment environment. Production startup requires these
values; HTTPS redirects, secure cookies, and HSTS are enabled automatically.
The app rejects request bodies larger than 11 MB and accepts 10 MB uploads only
when their extension and file signature match PDF, DOCX, image, or ZIP formats.

## <picture><source media="(prefers-color-scheme: dark)" srcset="assets/readme-icons/shield-lock-dark.svg"><img src="assets/readme-icons/shield-lock.svg" alt="" width="22" height="22" align="absmiddle"></picture> Security

The project relies on Django's built-in security and authentication mechanisms wherever appropriate.
GitHub Actions runs a scheduled weekly `pip-audit` scan of the runtime dependencies.

| Mechanism | Purpose |
|:---|:---|
